## Проекты и опыт

### Магистерская работа: предсказание EC-номеров ферментов
Пайплайн: сбор данных из четырёх источников, предсказания готовых моделей (ProteInfer, CLEAN), верификационный фильтр по оперонному контексту, стратифицированная оценка качества.
- F1 macro **0.807 → 0.887**, accuracy 0.967 → 0.982 при падении покрытия 0.879 → 0.716 — фильтр отказывается от неуверенных предсказаний вместо того, чтобы ошибаться в них
- Наибольший прирост там, где модель слабее всего: **+0.124 F1** на низкогомологичных белках
- Строгая валидация: стратификация по гомологии (MMseqs2), исключение утечки данных по последовательности, воспроизводимый пайплайн
- Источники данных: ODB, RefSeq, UniProtKB, KEGG; разбор PDF (`pdfplumber`)
- Репозиторий: [prokaryotic-ec-operon-filter](https://github.com/Kain420/prokaryotic-ec-operon-filter)

### Spotify Churn Analysis: диагностика отсутствия сигнала в данных
Проект с отрицательным результатом и набором экспериментов, показывающих, что результат верен, а не является ошибкой моделирования.
- Пять контрольных экспериментов: проверка пайплайна на данных с заведомым сигналом, сравнение реальных меток с намеренно перемешанными, разбор того, что даёт балансировка классов, калибровка оценки взаимной информации, демонстрация переобучения
- ROC-AUC **0.50** на всех моделях и стратегиях препроцессинга; настроенная модель проигрывает константному предсказателю
- Практический вывод: как отличить «модель недоучена» от «в данных нет сигнала» до того, как тратить время на тюнинг
- Репозиторий: [spotify-churn-analysis](https://github.com/Kain420/spotify-churn-analysis)
